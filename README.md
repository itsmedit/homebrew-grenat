# Homebrew tap for Grenat

```sh
brew install itsmedit/grenat/grenat
```

[Grenat](https://github.com/itsmedit/grenat) is an agentic programming language:
Ruby's syntax, Rust's speed. The formula installs `grenat` and `setter`, and the
runtime libraries `grenat build` links. It is written from each release by
`scripts/homebrew-formula.sh` in the Grenat repository.
